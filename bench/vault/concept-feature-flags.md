# Feature flags

Ship code switched off and turn it on for a few users first, so a bad change can be undone without a deploy.

Projects that rely on it: [[project-osprey|Project Osprey]], [[project-godwit|Project Godwit]], [[project-dipper|Project Dipper]], [[project-garganey|Project Garganey]].
