# Project Merlin

The goal of Project Merlin is to index every recorded seminar by speaker and topic. Project Merlin is led by [[person-yara-delacourt|Yara Delacourt]]. Project Merlin started in June 2021.

Project Merlin is built on [[tool-corvex|Corvex]]. Project Merlin depends on [[project-shrike|Project Shrike]].
