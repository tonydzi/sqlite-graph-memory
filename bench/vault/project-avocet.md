# Project Avocet

The goal of Project Avocet is to keep the visitor badge system running during outages. Project Avocet is led by [[person-vesna-thorsby|Vesna Thorsby]]. Project Avocet started in December 2019.

Project Avocet is built on [[tool-siltcore|Siltcore]].
