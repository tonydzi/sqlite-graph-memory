# Idempotent writes

Repeating the same write leaves the data in the same state, which makes retries safe.

Projects that rely on it: [[project-kestrel|Project Kestrel]], [[project-plover|Project Plover]], [[project-avocet|Project Avocet]], [[project-skua|Project Skua]], [[project-nightjar|Project Nightjar]].
