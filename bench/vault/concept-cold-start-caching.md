# Cold-start caching

Warm the cache before traffic arrives so the first users of the day do not pay for an empty cache.

Projects that rely on it: [[project-merlin|Project Merlin]], [[project-curlew|Project Curlew]], [[project-petrel|Project Petrel]], [[project-siskin|Project Siskin]].
