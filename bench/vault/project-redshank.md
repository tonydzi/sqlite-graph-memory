# Project Redshank

The goal of Project Redshank is to predict which builds will fail before they run. Project Redshank is led by [[person-ines-rautio|Ines Rautio]]. Project Redshank started in June 2022.

Project Redshank is built on [[tool-mosscache|Mosscache]]. Project Redshank depends on [[project-heron|Project Heron]].
